- Trusted-proxy sources: `gateway.trustedProxies` names the front proxy's address pool (`NETWORK_ROLE_SUBNET_POOL` in compose, Docker's default overlay pool in swarm), not its exact source address. Cause: compose reaches the published port through the gateway of whichever role network Docker binds the port to, and the swarm overlay of `svc-prx-openresty` has no fixed subnet, so no lookup returns that address. Forged identities are refused by the proxy-owned secret header in `requiredHeaders` regardless. Options: a shared lookup that returns the front proxy's source address per deployment mode (a fixed IPAM subnet for the openresty overlay, a pinned gateway network for published ports).
